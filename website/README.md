# Incident Radar website

Standalone frontend for the Incident Radar project: product landing plus an ops console with incidents, events, services, ACT/ASK/NOTIFY simulation, and the policy engine.

## Run

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

This site uses demo telemetry from the repo and does not call Workato or the Next.js API.
